4. Subdivisions de l’anatomie P2

  • Échelle : macroscopique / microscopique (histologie)
  • Descriptive : morphologie externe (vues) vs interne (coupes)
  • Générale : par appareil ⭐ (= regroupement par fonction ⭐)
  • Topographique : disposition et rapports dans les régions
  • Fonctionnelle : morphologie ↔ fonction
  • Développement · Comparée

Appareil : groupement de systèmes pour une même fonction, éventuellement dans des régions différentes.

Appareils : locomoteur, cardio-vasculaire, respiratoire, digestif, endocrinien, urinaire, génital, nerveux, sensoriel.

Cavités : crânienne, thoracique, abdominale, pelvienne, canal vertébral — pas de cavité dans les membres. Hanche = coxale ⭐.

5. Les 3 plans de référence P1

Souvent tombé Section la plus dense en notions tombées.

Les 3 plans sont perpendiculaires entre eux.

  • Frontal / coronal ⭐ : vertical ⭐, parallèle au front / face ventrale ⭐, d’avant en arrière
  • Sagittal : vertical ⭐, droite/gauche ⭐. Médian : centre ⭐ → moitiés égales ⭐ mais non symétriques. Paramedians : s’éloignent de l’axe
  • Axial / transversal : horizontal, perpendiculaire à l’axe vertical ⭐ — le plus utilisé en imagerie
Attention / piège — coupes axiales Vues du dessous : avant en haut, arrière en bas ; droite et gauche inversées sur l’image.
